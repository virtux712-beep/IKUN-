## 📖 关于

「ikun之家」是 ikun 们自娱自乐的线上小窝：文化档案、可玩的投篮挑战、能弹的坤坤琴键、每天一抽的今日坤签。粉丝自制、纯属好玩，与任何官方无关。
本仓库存放该网站的全部源码，根目录 `index.html` 即线上首页（单文件，无构建步骤）。

## 🛠 技术与托管

- 纯静态站点：HTML / CSS / JavaScript，单文件
- 托管：ByetHost 免费主机（5 GB 空间，流量不限）
- 互动实现：Canvas 式跑针投篮小游戏、WebAudio 五声音阶琴键、随机坤签
